# Sorting Visualizer

A sorting algorithm visualizer written in C.

This is a project I'm building to learn more about sorting algorithms and understand how they work step by step, instead of just seeing the final sorted array.

For now, the project runs in the terminal and includes Bubble Sort with a simple visualization.

## What it can do

* Take an array from the user
* Sort the array using Bubble Sort
* Show the sorting process in the terminal
* Let the user choose a sorting algorithm

## Built with

* C
* GCC
* Linux Terminal

## How to run

Clone the repository:

```bash
git clone https://github.com/adithyauday123-ui/Sorting-Visualizer.git
cd Sorting-Visualizer
```

Compile:

```bash
gcc src/main.c -o visualizer
```

Run:

```bash
./visualizer
```
